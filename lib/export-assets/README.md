# PDF fonts

The auction PDF embeds Noto Sans Regular and Bold so names, punctuation and currency symbols remain searchable text. These fonts are packaged server assets; downloads do not contact an external font host.

- Source: [Noto Fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans)
- Copyright: The Noto Project Authors
- License: SIL Open Font License 1.1, reproduced in [OFL.txt](./OFL.txt)

The fonts are not included in the browser bundle.
